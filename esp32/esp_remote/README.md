### This code is meant for ESP 32

This code works with the online Web Remote at https://helloworld.co.in/iot/remote/

Create an account <a href='https://helloworld.co.in/iot'>here</a> to get your remote
and your auth_token. The token is shown on that page when you are signed in, and
emailed to you the first time you log in.

### Procedure to use

1. Download this code. Put your wifi credentials and your auth_token in
   `esp_remote.ino`, in place of the `xxxxxx` placeholders.

2. Upload it to your ESP 32 with the Arduino IDE.

3. Power the ESP 32 from a power bank or a USB port.

4. Configure the Web Remote and pick the GPIOs you want to control.

5. Start controlling the GPIOs of your ESP 32 from the Web Remote.
